# v1.9 Final Release Notes

**Release:** Solar PV Design Platform v1.9 final  
**Project schema:** 1.9  
**Rule engine:** 1.9.0  
**Server:** 1.9.0

## Cumulative milestone

v1.9 is cumulative. It retains v1.7 functionality, carries the v1.8 engineering-rule-pack milestone forward, and completes the v1.9 rule-governance/audit layer.

## Added in the v1.8 cumulative layer

- Explicit versioned engineering rule-pack engine.
- Rule ID/version, jurisdiction metadata, standard/reference metadata and completeness status.
- Deterministic cable/protection tables and configurable preliminary assumptions.
- Conductor material, insulation, installation-method, ambient and grouping correction factors.
- Voltage-drop, design-current, PE, SPD, access/setback and protection prompts.
- Legacy v1.7 compatibility pack.
- Validation and explicit preliminary-engineering limitations.

## Completed in v1.9

- Project JSON overlays on built-in rule packs without changing base pack identity/version.
- Prototype-pollution key blocking in overlays.
- Deterministic `rule-xxxxxxxx` fingerprint of resolved configuration/provenance.
- Rule-decision trace table with basis and limitations.
- Scenario comparison across rule contexts.
- Rule-aware detailed electrical cable/protection/PE calculation inputs.
- Engineering-rule configuration persisted in project snapshots and revisions.
- Migration of compatible older snapshots to explicit rule provenance.
- Rule-pack validation added to project validation.
- Rule provenance added to electrical object model, SLD SVG metadata/subtitle, BOM CSV provenance, and engineering-report metadata/provenance/trace.
- Section 17 added without removing the original 16 application sections.
- v1.9 server health reports application and project-schema provenance/capabilities.

## Intentionally unchanged / preserved

- Stable design-surface and sub-array identity behavior.
- Physical geometry/layout and manual editing architecture.
- String/MPPT design path and inverter limits.
- Energy, finance, revision/fingerprint, repository and Worker-fallback architecture.
- Default SQLite repository filename remains `solar_pv_v17_alpha6.sqlite3` to avoid an unrequested repository migration.

## Not claimed

Built-in rule packs are preliminary and are not construction-ready code-compliance implementations. No claim is made that IEC/NEC/local standards are fully encoded or independently validated.
