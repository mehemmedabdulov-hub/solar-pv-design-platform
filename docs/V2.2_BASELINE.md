# SOLAR v2.2 Baseline Note

Date: 2026-09-03

Before feature changes, the supplied SOLAR v2.1 repository was treated as the protected engineering baseline and `bash tests/run_v21_verification.sh` was executed successfully.

## Baseline UI observations

- The application contained the complete professional shell but still exposed 17 major card sections in the primary long-scroll journey.
- Site drawing, equipment/layout, manual panel editing, electrical design and deliverables were separated vertically, requiring repeated context switching.
- Manual panel editing supported a single selected panel plus add/move/rotate/delete operations and relied on the exact geometry validator for accepted edits.
- SLD output was a deterministic SVG block diagram generated from the existing electrical object model.
- Existing core deliverables were SLD SVG, BOM CSV and HTML/print report.
- There was no supplied `.devcontainer`.

## Protected baseline checks

The baseline suite passed calculation regression, runtime/static wiring, server/API/revision behavior, frozen-v1.9 hashes, retained v1.9 rule-pack regression, v2.0 rule-pack contract tests and project-migration tests. That result is the regression guardrail for v2.2.
