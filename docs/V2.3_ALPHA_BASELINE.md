## Baseline gaps selected for Alpha

1. Ordinary map interaction could change project coordinates after location-bound geometry existed.
2. Installation radio changes over existing geometry immediately rewrote surface metadata.
3. `updateDesignResults()` and metadata handlers rebuilt engineering deliverables in ordinary foreground refresh paths.
4. Critical Alpha-touched paths still used blocking browser alerts and v2.3 release wiring/tests/docs did not yet exist.
